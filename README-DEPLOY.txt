ZAPHYRA — PACOTE AUTOCONTIDO PARA GITHUB PAGES

Este pacote deve ser extraído e o CONTEÚDO interno enviado para a raiz da branch/pasta que o GitHub Pages publica.

Conteúdo incluído:
- index.html: página em português, com CSS, JavaScript e todas as ilustrações embutidos.
- en/index.html: versão em inglês, também autocontida.
- .nojekyll: desativa processamento Jekyll para arquivos estáticos.
- CNAME: preserva zaphyra.xyz.
- favicon.svg e robots.txt.

IMPORTANTE:
1. Envie os arquivos e a pasta en/ diretamente para a raiz publicada; não envie a pasta extraída como subpasta.
2. Não é necessário enviar uma pasta assets/: as imagens e o desenho botânico estão embutidos nos HTMLs, para evitar falhas de caminho de imagem.
3. O CSS e o JavaScript também estão embutidos. As fontes Google são melhoria progressiva; se não carregarem, há fontes alternativas.
4. O booking está deliberadamente sem link externo até que seja encontrada a URL pública real do sistema.
5. Após publicar, aguarde a ação GitHub Pages terminar e atualize o navegador com Ctrl+F5.

O domínio CNAME está configurado para zaphyra.xyz.
