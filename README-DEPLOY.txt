ZAPHYRA — PACOTE DE PUBLICAÇÃO DIRETA

ESTE ZIP JÁ ESTÁ ORGANIZADO PARA A RAIZ DO REPOSITÓRIO GITHUB PAGES.

1. Baixe e extraia o ZIP no computador.
2. Abra a pasta extraída e selecione TODO o conteúdo interno: index.html, en/, assets/, favicon.svg, CNAME, .nojekyll, robots.txt e este README.
3. Envie esses arquivos e pastas diretamente para a raiz do repositório SantiagoLigorio/Zaphyra, substituindo os arquivos com o mesmo nome. NÃO coloque a pasta inteira dentro de outra pasta e não envie somente o ZIP.
4. Confirme que GitHub Pages está configurado para publicar a branch main a partir da raiz (/).
5. Aguarde a ação Pages terminar com sucesso. Depois, recarregue zaphyra.xyz com Ctrl+F5 (ou Cmd+Shift+R no Mac).

POR QUE ESTE PACOTE É MAIS ROBUSTO
- O CSS e o JavaScript estão embutidos em index.html e en/index.html, sem dependência de buscar esses dois arquivos externos para renderizar o layout.
- As gravuras e a ilustração lateral estão em assets/ com caminhos relativos verificados.
- .nojekyll impede o processamento do Jekyll; CNAME preserva o domínio zaphyra.xyz.
- Não exige npm, build, bundler ou instalação de dependências.
- O booking está temporariamente inativo porque o link fornecido anteriormente era o repositório de código, não a URL pública da aplicação. Quando a URL de produção for localizada, basta trocar o CTA nas duas páginas.
